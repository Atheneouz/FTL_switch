======================================================================
  FTL: Faster Than Light - Nintendo Switch Port (HOME Menu Forwarder)
======================================================================

You can build and install a custom HOME Menu forwarder for FTL:

Building the Forwarder NSP:
----------------------------------------------------------
Run:
    python tools/build_nsp.py

Requirements:
- Python 3 with 'nton' installed (`pip install nton`)
- Switch encryption keys located at ~/.switch/prod.keys

Output:
- Generates `instalacion/FTL_Forwarder_[0100F71016210000].nsp`
- Launches directly from: sdmc:/switch/ftl/ftl.nro

======================================================================
  INSTALLATION STEPS ON YOUR NINTENDO SWITCH
======================================================================

1. Prepare game files on your MicroSD:
   - Place your 'FTL_xxx.ipa' file into the 'ipa/' folder.
   - Run:
       python tools/prepare_sd_card.py
   - Copy the 'switch' folder from 'sd_card/' to the root of your MicroSD.

2. Install the Forwarder on your console (Optional):
   - Generate the forwarder NSP using `python tools/build_nsp.py`.
   - Install `instalacion/FTL_Forwarder_[0100F71016210000].nsp` using DBI,
     Goldleaf, or your preferred NSP installer.

3. Alternatively, launch `FTL` directly from the Homebrew Menu (Album).

======================================================================
  VERSION EN ESPAÑOL
======================================================================

Puedes generar e instalar un acceso directo (Forwarder) para el menú HOME:

Generación del Forwarder NSP:
----------------------------------------------------------
Ejecuta:
    python tools/build_nsp.py

Requisitos:
- Python 3 con 'nton' instalado (`pip install nton`)
- Claves de la consola en ~/.switch/prod.keys

Resultado:
- Genera `instalacion/FTL_Forwarder_[0100F71016210000].nsp`
- Ejecuta directamente: sdmc:/switch/ftl/ftl.nro

======================================================================
  PASOS DE INSTALACION EN TU NINTENDO SWITCH
======================================================================

1. Preparamos los datos del juego en la MicroSD:
   - Coloca tu archivo 'FTL_xxx.ipa' en la carpeta 'ipa/'.
   - Ejecuta:
       python tools/prepare_sd_card.py
   - Copia la carpeta 'switch' de 'sd_card/' a la raíz de tu MicroSD.

2. Instalamos el Forwarder en la consola (Opcional):
   - Genera el forwarder NSP ejecutando `python tools/build_nsp.py`.
   - Instala `instalacion/FTL_Forwarder_[0100F71016210000].nsp` con DBI,
     Goldleaf o tu instalador de paquetes favorito.

3. O bien abre el juego directamente desde el Homebrew Menu (Álbum).
